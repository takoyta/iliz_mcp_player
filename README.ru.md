# iliz MCP player

Удобный, простой и красивый плеер для Windows. Одно окно: сверху управление, снизу очередь. Перетащил файлы или папку — они в плеере.

Плеер сам отдаёт [MCP](https://modelcontextprotocol.io) для AI-агентов. Cursor, Claude Code и другие могут найти трек, включить его, поставить лайк или переключить дальше, пока окно свёрнуто в трей.

## Система

- Windows 10 / 11 (x64)
- Без установщика: распаковал и запустил
- Второй запуск не открывает копию: файлы из командной строки уходят в уже работающий плеер

Воспроизведение через [BASS](https://www.un4seen.com/): MP3, WAV, OGG, AIFF и другие встроенные форматы.

Очередь, лайки, счётчик прослушиваний и поисковый индекс лежат в `%APPDATA%\iliz\iliz_mcp_player\library.db`.

## Как пользоваться

Перетащи файлы или папки на окно. Если сейчас ничего не играет, первый добавленный трек начнётся сам.

- Пробел — пауза / продолжить. Enter — играть выбранное. Delete — убрать из очереди.
- Стрелки и Page Up / Page Down — выбор. Влево / вправо — перемотка на 5 секунд.
- Клик по полоске — перемотка. Колёсико на громкости — громче или тише, клик по динамику — mute.
- Сердце или Ctrl+L — лайк. Рядом кнопки «только лайки» и «уже слушали».
- Поле поиска фильтрует очередь по названию. Ctrl+A — выделить видимые, Ctrl+клик и Shift+клик — несколько строк.
- Перемешивание, «поверх всех окон».
- Медиаклавиши (play/pause, next, previous, stop) работают и из трея.
- Esc или крестик — спрятать в трей. Ctrl+клик по крестику — выйти.
- Клик по иконке в трее — показать окно. Двойной клик — пауза или продолжить. Правый клик — показать, открыть папку с данными, о программе, выйти.
- Правый клик по треку — копировать название, теги, убрать из очереди, удалить файл с диска.

## MCP

Плеер — это MCP-сервер. Сначала запусти его, потом укажи агенту адрес. Клиент плеер сам не стартует: это не stdio-процесс.

Пока плеер работает, сервер слушает только localhost:

`http://127.0.0.1:17321/mcp`

Cursor, Claude Desktop, Claude Code, MCP Inspector — в пользовательский конфиг MCP:

```json
{
  "mcpServers": {
    "iliz-player": {
      "url": "http://127.0.0.1:17321/mcp"
    }
  }
}
```

Если клиент просит тип транспорта явно, добавь рядом с `url` поле `"type": "http"`.

Инструменты те же, что и REST. `play` лучше вызывать с `id` из `search`. Ошибки приходят как `isError` и те же строки `error`, что у HTTP.

| Инструмент | Аргументы | Что делает |
| --- | --- | --- |
| `search` | `query` | Ищет по названию, исполнителю, альбому и имени файла. Пустой запрос — очередь, не больше 50. Поле поиска в окне не меняет. |
| `now` | — | Что сейчас: `playing`, `paused` или `stopped`, название, исполнитель, позиция. Воспроизведение не трогает. |
| `play` | `id`, `query` | Включает трек. `id` важнее; `query` берёт первый найденный. Это не пауза. |
| `skip` | `dir` | Следующий или предыдущий в очереди. `dir`: `next` (по умолчанию) или `prev`. При перемешивании следующий — случайный. Предыдущий, если прошло больше 3 секунд, начинает текущий сначала. |
| `like` | `id`, `liked` | Лайк. Без `id` — текущий трек. `liked` 1 или 0 задаёт явно, без него — переключает. |
| `stop` | — | Стоп и сброс текущего трека. Это не пауза. |

Обычный ход агента: `now` или `search` → взять `id` → `play` → `skip` → `like` → `stop`.

Тот же API есть как обычный HTTP, например `http://127.0.0.1:17321/search?q=love`. Протокол, поля ответа и ошибки — в [HTTP.ru.md](HTTP.ru.md).

## Сборка

Нужны Visual Studio Build Tools 2022 (MSVC x64) и `bass.dll` в `bin\`.

```bat
build.bat
```

## Тесты

Python 3, только стандартная библиотека. Сначала собери плеер (`bin\iliz_mcp_player.exe` и `bass.dll`).

```bat
python tests\test_player.py
```

Тест поднимает свой плеер на свободном `--port` и пишет временный плейлист в отдельный `APPDATA`. Твоя очередь не затрагивается. На время прогона мелькнёт окно плеера.

Новые поисковые кейсы — строка `(query, titles)` в `Search.test_table` в `tests\test_player.py`.

## Доработать

Исходники в этом репозитории, собираются одним `build.bat`. Если чего-то не хватает — кнопка, жест, инструмент для агента — это можно сделать самому в Claude Code, Cursor или похожем редакторе: открой проект и опиши, что должно измениться.
